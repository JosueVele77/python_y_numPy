## 📖 Acerca del proyecto

Este repositorio reúne un **taller práctico de nivelación en Python y NumPy** desarrollado en un notebook de Google Colab. El material repasa estructuras de datos, funciones y operaciones numéricas, desde los conceptos esenciales hasta la manipulación de arrays multidimensionales.

El notebook combina **explicaciones, ejemplos de código y ejercicios prácticos** para facilitar el aprendizaje progresivo.

> 🎯 **Objetivo:** reforzar las bases de programación en Python y desarrollar habilidades para crear, transformar y analizar arrays con NumPy.

## 🧭 Contenido del taller

| Módulo | Tema | Contenidos |
|:---:|---|---|
| **01** 🐍 | **Python esencial** | Listas, list comprehensions, tuplas, diccionarios y funciones |
| **02** 🔢 | **Fundamentos de NumPy** | Creación de arrays, funciones de generación y atributos de `ndarray` |
| **03** 🧩 | **Indexing y reshape** | Acceso a elementos, slicing, máscaras booleanas, fancy indexing y cambio de forma |
| **04** 📊 | **Operaciones numéricas** | Vectorización, broadcasting, estadística, concatenación y ordenamiento |

## 🧪 Prácticas incluidas

- **Módulo 1:** comprensiones de listas, filtrado de diccionarios, funciones de resumen y uso de `map()`.
- **Módulo 2:** generación de vectores y matrices, números aleatorios reproducibles, tipos de datos y matriz identidad.
- **Módulo 3:** extracción de submatrices, máscaras booleanas, transformaciones con `reshape()` y diferencias entre vistas y copias.
- **Módulo 4:** estadística por columnas, normalización, broadcasting, análisis de notas y concatenación de matrices.

## 🚀 Cómo ejecutar el notebook

**Opción recomendada: Google Colab (sin instalación local)**

1. Haz clic en el botón **Abrir notebook en Google Colab** del encabezado.
2. Espera a que se cargue el cuaderno.
3. Ejecuta las celdas en orden usando **Shift + Enter**.
4. Revisa los resultados y modifica los ejercicios para practicar.

**Opción local (Jupyter Notebook)**

Si ya tienes Python y Jupyter instalados, puedes clonar este repositorio:

```bash
git clone https://github.com/JosueVele77/python_y_numPy.git
cd python_y_numPy
pip install numpy notebook
jupyter notebook Practica1_Taller_de_Numpy.ipynb
```

> ℹ️ Google Colab suele incluir NumPy preinstalado, por lo que no es necesario instalarlo allí.
